# 밸런스 검토 (v0.2 기준)

대상: Risulike RPG.js v0.2 (main 2f9bd3d). 헤드리스 자동 플레이 시뮬레이터로 직업 16 × 난이도 6 × 250런(24,000런), 변형·조정 후보 실험 약 39,400런, 조정 후 재측정 24,000런과 스킬·동료 벤치마크를 돌린 결과입니다. 결론부터:

- 난이도 곡선은 3(어려움)→4(악몽) 사이가 절벽입니다(클리어 40.8% → 14.5%). 고난이도 사망의 대부분이 1~3층 보스·엘리트에서 나옵니다.
- 레트킹(1층 보스) 한 마리가 전체 사망의 33.7%를 차지합니다. 연속공격 경로가 방어·피해감소를 무시하고 난이도 고정% 피해를 타격마다 받는 구조라서입니다 → 유일하게 적용한 수치 조정(연속공격 배율 0.6→0.45).
- 직업 간 격차는 1~4단계 평균 클리어율 기준 사냥꾼 72% ~ 광대 41% (약 31%p).
- v0.2 기능: 봇 동료는 리리스 루트보다 강하고(+3.6%p), 봇 특별 보스는 1층에서 부르면 손해(소환 전투 사망 15%, 보상 EXP 73), 동료 역할은 런 전체로는 유의한 차이가 없지만(±1.3%p 이내), 보스전 단위로는 리리스 '공격'이 8개 시나리오 모두에서 우위(+5.4%p)라 지배 전략에 가깝고 보호·탐색은 기본보다도 낮습니다. 헬레나 역할은 차이가 작습니다.
- 밸런스와 별개로 보스전 소프트락 결함을 찾았습니다(24,000런 중 149회, 재현 시드 포함). 수치 조정 범위 밖이라 고치지 않았습니다.

> 이 숫자는 규칙 기반 정책 AI의 결과입니다. 실제 플레이어(특히 숙련자)는 문 선택·장비 해제·포션 타이밍·저주 장비 회피를 더 잘하거나 다르게 하고, 별의 파편(메타 진행)도 씁니다. 절대 수치보다 같은 정책 안에서의 상대 비교(직업 간, 적 간, 조정 전/후)로 읽어 주세요. 한계는 7절 (#7-한계)에 정리했습니다.

## 1. 방법

### 1.1 시뮬레이터 (tools/sim/)

| 파일 | 역할 |
|---|---|
| engine.cjs | tests/game.test.cjs와 같은 방식으로 게임 파일을 jsdom 창에서 평가(await initRPG();를 훅으로 치환해 내부 함수 접근). setTimeout은 가상 시계 큐로 즉시 순서대로 실행(적 턴·승리 처리·동료 지원이 타이머에 걸려 있음), Math.random은 시드 고정 mulberry32, 렌더·연출·사운드·저장·도감 기록은 끔. 런마다 소스를 다시 평가해 전역 상태를 초기화 |
| policy.cjs | 규칙 기반 정책 (1.2) |
| run-game.cjs | 새 게임(난이도→직업→여성) → 사망·클리어까지 진행, 런당 기록 1줄 |
| simulate.cjs | worker 4개 병렬, JSONL 출력. 시드 = f(기본 시드, 직업, 난이도, 회차)라 변형 실험끼리 같은 시드로 짝 비교 |
| analyze.cjs · compare.cjs | 집계(Wilson 95% 신뢰구간, 생존 편향 보정 이상치), 짝 비교(같은 시드 쌍의 차이와 95% CI) |
| skill-bench.cjs · ally-bench.cjs | 스킬 91개 효율, 동료/역할 보스전 비교 |

정책은 실제 화면에 있는 버튼만 누릅니다. 현재 단계의 렌더 함수(renderDoorChoices/renderBattleArea/renderEventArea/renderBossCleared/renderMutationChoice)가 만든 HTML에서 data-action 버튼을 읽고 비활성(쿨다운) 버튼은 빼고 고릅니다. 직접 호출은 (1) 전투 밖 포션(usePotionByKey, 화면의 포션 버튼과 같은 함수), (2) 봇 소환·역할 설정 실험, (3) 소프트락 우회(4.1)뿐입니다.

속도를 위해 시뮬레이터 안에서만 findEquipDefById(선형 탐색→Map)와 ensurePlayerSlotData(장비 구성이 같으면 재계산 생략)를 같은 결과를 내는 버전으로 바꿨습니다. 같은 시드 32런의 전체 기록이 교체 전과 바이트 단위로 동일함을 확인했습니다. 내장 이미지 base64는 로드 시 짧은 자리표시로 바꿉니다(로직 무관). 런당 약 0.05~0.4초.

### 1.2 정책 (요약)

| 상황 | 규칙 |
|---|---|
| 전투 | HP 35% 미만이면 포션(턴 소모 없음) → HP 60% 미만이면 회복 스킬 → 쿨다운 된 무료(턴 소모 없음) 버프/디버프(HP 소모형은 HP 60% 이상일 때만) → 보스 강공격 예고(_bossCharging) 시 방어 → 궁극기 → 주사위 기대값이 가장 큰 공격 스킬 → 기본 공격 |
| 문 | 문 종류별 (보상, 위험) 점수표, 위험 가중치 = 1 + 2.5×(1−HP비율). 용의 둥지는 레벨 ≥ 층+2이고 HP 90% 이상일 때만 |
| 전투 밖 | HP 45% 미만이면 문 선택 전에 포션 |
| 상자 | 감정 → 해체(DEX). 미믹으로 감정됐고 HP 50% 미만이면 무시 |
| 신단 | WIS 판정 성공 확률 ≥ 50%면 기도 |
| 축복/서재/계약 | 패시브는 희귀도 순, 스킬은 희귀도+기대 피해, 보상 카드는 패시브>능력치>경험치>골드. 악마의 거래는 HP 75% 이상일 때 보상가치/HP대가 최대 |
| 상인 | 포션 부족(2+층/3 미만) 시 포션 > 미보유 장비(희귀도) > 스킬 > 즉사방지 부적(여윳돈) > 수련서 > 미스터리 박스 |
| 대장간 | 화면 정렬상 첫 번째(성공률 높은) 강화 가능 장비, 2회차 시도 / 천상의 대장간은 가장 높은 등급 |
| 돌연변이·황금 고블린·전설 제단 | 고정 선호 순(강철 피부·재생력·…), 전설 장비 > 능력치 > 골드 |
| 퀘스트 | 리리스: 돕기 → 보호(HP 60%↑)/분배 → 결혼. 그 외 수락·해방 위주 |
| 장비 | 이 버전은 보유한 모든 장비 능력치가 자동 적용되고 전설/신화 패시브는 빈 슬롯에 자동 장착되므로 별도 장착 정책 없음 |

정책 민감도(난이도 1~6 × 직업 16 × 10런 예비 실험): '보스 강공격 예고 시 방어' 하나로 보통 62→85%, 어려움 23→40%로 크게 변했습니다. 용의 둥지를 HP 80%면 무조건 들어가면 보통 64→48%. 반대로 포션 기준 35%→50%는 유의한 차이가 없었습니다(어려움 40.0 vs 41.3%). 즉 결과는 '예고를 보고 방어하는가'와 '드래곤 회피'에 민감합니다.

급경사 구간:

1. 1층이 가장 위험한 층입니다(어려움 18%, 악몽 37%, 지옥 62%, 나락 92%). 레벨 1~2(사망 시 평균 레벨 1.2)에서 난이도의 고정값 보정(적 피해 +2~+6, 매 피격 최대HP 7~20% 고정 피해, DIFFICULTY_DEFS Risulike RPG.js:4382)이 가장 크게 작용하기 때문입니다. 지옥·나락은 사실상 1층에서 끝나는 난이도입니다.
2. 3층 급등(어려움 2층 12% → 3층 19%): 해골 장군(부활 시 HP 50%·피해 ×1.5, :11319).
3. 7층 소폭 급등(어려움 6층 3% → 7층 8%): 암흑기사.
4. 4층 이후는 대체로 완만합니다. 즉 이 게임의 난이도는 "후반 누적형"이 아니라 초반 몇 판에 몰린 형태이고, 4~10층은 초반을 넘긴 캐릭터에게 상대적으로 쉽습니다.

- 봇 동료(70.0%)는 결혼 리리스 기본(74.5%)보다 낮지만 동료 없음(57.0%)보다 13%p 높습니다. 결혼 전 리리스(20%·8%)는 이 벤치에 넣지 않았습니다.

## 7. 한계
 +- **정책 AI ≠ 실제 플레이어.** 규칙 기반이라 상황 판단(적 패턴 학습, 포션을 아끼거나 몰아 쓰기, 위험한 방 회피)이 단순합니다. 사망 런이 평균 포션 2~4개를 남기고 죽는 것도 그 예입니다(포션 기준 상향은 유의한 차이가 없었음). 저주 장비를 빼지 않고, 상점 판매·제작·분해·별의 파편 상점·무한 모드·휴식(채팅 연동)은 쓰지 않습니다. 성별은 여성 고정(능력치 차이 없음). +- **메타 진행 없음.** 별의 파편 효과(시작 골드·포션·HP·고정 피해 감소 등)가 0인 신규 계정 기준입니다. 실제 고난이도 도전자는 이 보정을 받습니다. +- **실시간 요소.** 동료 팝업이 떠 있는 동안 동료 발동을 건너뛰는 등 벽시계에 의존하는 동작은 가상 시계로 "팝업이 사라진 뒤 행동"하는 것으로 처리했습니다(4.2 #12). +- **이상치 분석은 관측 연구**입니다. 생존 편향과 희귀도 효과를 보정했지만 "그 항목을 얻는 경로"(예: 특정 방을 더 많이 간 런)의 교란은 남습니다. 인과 판단은 조정 후보처럼 소스를 바꾼 짝 실험이 필요합니다. +- **스킬 벤치**는 공격하지 않는 적을 상대로 한 피해만 봅니다. 방어·회피·디버프의 생존 가치, HP 비례 스킬의 적 HP 의존성은 반영되지 않습니다. +- **봇 보스·역할 실험**은 난이도 2~3(일부 2~4)만 봤습니다. 봇 보스는 "그 층 이상 첫 문 선택 때 HP 80% 이상"이라는 한 가지 소환 규칙만 봤습니다. +- 실제 RisuAI 호스트, 모델 응답, 장시간 실기 플레이는 이번에도 검증하지 않았습니다.

¹ 시간 왜곡은 턴 종료 시 쿨다운 중인 스킬이 있으면 자동 발동하는 스킬이라, "쿨다운이 돌면 사용"하는 로테이션으로는 측정할 수 없습니다.
