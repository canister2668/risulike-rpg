# 신규 아이디어 · 제안 단계

다음 기능은 아직 구현하지 않았습니다. 저장 안정성과 검증을 먼저 확보한 뒤 추가하는 순서입니다.

| 순서 | 아이디어 | 사용자에게 생기는 변화 | 구현 방향 |
|---|---|---|---|
| 1 | 세이브 미리보기·복원 지점 | 가져오기 전에 교체되는 슬롯과 캐릭터를 확인하고 실수를 되돌림 | 슬롯별 비교, 명시적 교체, 마지막 정상 저장 1개 보관 |
| 2 | 전투 피해 명세 | 공격력·치명타·장비·감소율이 왜 그 피해가 됐는지 확인 | 실제 계산 단계에서 수치를 수집해 펼쳐보기 제공 |
| 3 | 빌드 도감 | 현재 빌드와 잘 맞는 장비·패시브를 게임 안에서 찾음 | 기존 buildAxis/태그 기반 추천, 미해금 항목은 숨김 |
| 4 | 시드 도전 | 같은 던전을 공유하고 버그를 재현 | 난수 발생기 분리, 시드·선택 기록·버전 저장. 일반 런과 기록 분리 |
| 5 | 짧은 원정 | 긴 플레이가 어려울 때 3층 목표를 선택 | 기존 콘텐츠를 재사용한 별도 모드, 기존 10층 보상과 분리 |
| 6 | 동료 역할 선택 | 리리스·헬레나의 행동을 플레이 스타일에 맞춰 선택 | 공격/보호/탐색 역할, 기존 대사와 합류 조건 유지 |
| 7 | 효과 줄이기·음량 설정 | 모바일에서 움직임과 소리를 조절 | prefers-reduced-motion, 이펙트 단계, 음량 0 지원 |

구조 개선은 데이터/저장/전투/화면을 소스 모듈로 분리하되, 설치 파일은 지금처럼 JS 하나로 빌드하는 방향이 적합합니다. 전투 타이머에 런·전투 ID를 부여하고 저장 포맷 버전을 명시하면 이후 기능 추가와 재현 테스트도 수월해집니다.
