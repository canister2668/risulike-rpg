# Risulike RPG · v0.1

RisuAI API v3용 던전 RPG 플러그인입니다. 직업 16종, 스킬 91개, 패시브 117개, 장비 196개, 적 51종과 5개 캐릭터 저장 슬롯을 제공합니다.

사용자가 제공한 기존 `9.1.4` 파일을 바탕으로 GitHub 배포 버전을 **0.1부터 새로 시작**합니다. `package.json`만 npm 형식에 맞춰 `0.1.0`입니다. 내부 플러그인 이름과 기존 저장 키는 유지합니다.

## 설치

1. `Risulike RPG.js`를 다운로드합니다.
2. 기존 버전 사용자는 게임의 내보내기로 저장 코드를 먼저 보관합니다.
3. RisuAI 설정 → 플러그인에서 JS 파일을 가져옵니다. 같은 이름의 기존 플러그인은 업데이트합니다.
4. RPG 액션 버튼으로 게임을 엽니다.

기본 UI는 공식 클라이언트의 전체화면 컨테이너를 사용합니다. 기존 파일의 floating 지원 탐지는 유지하며, 지원하지 않는 호스트에서는 전체화면으로 동작합니다. 휴식 대화 연결은 RisuAI의 요청 수정 권한이 필요합니다.

일반 설치에 npm이나 별도 서버는 필요하지 않습니다. 이미지는 JS 안에 포함되어 있습니다.

## 이번 변경

- 비동기 자동저장 시 플레이어·진행·슬롯을 함께 고정하고 저장 순서를 보장합니다.
- 구형 저장 코드 가져오기에서 저장 완료 전 상태를 지우던 문제를 수정했습니다.
- 가져오는 슬롯 범위와 필수 게임 데이터를 전체 검사한 후 쓰기를 시작합니다.
- 묘지·도감 초기 로드 및 도감 반복 조우 횟수 저장을 수정했습니다.
- 전설 슬롯 선택 변수 누락, 직업명 참조, 이미지 중복 키를 정리했습니다.
- 승리 연출 중복 및 이전 게임의 지연된 승리 처리, 비활성 턴의 쿨다운 소비를 방지합니다.
- 휴식 문맥은 선택한 캐릭터의 일반 채팅 요청에만, 마지막 user 메시지 앞에 추가하고 카드의 depth prompt를 수정하지 않습니다. 휴식 중 저장한 게임을 불러오면 다시 연결합니다.
- `onUnload` 미지원 호스트에서도 RPG 버튼이 등록되고, 일부 필드가 빠진 구버전 슬롯도 불러옵니다.

이전 버전이 이미 카드에 남긴 `<!--RPG_START-->` ~ `<!--RPG_END-->` 구간은 자동으로 삭제하지 않습니다. 기존 휴식 문구가 남아 있다면 해당 카드의 depth prompt에서 그 구간만 제거하세요.

## 개발 및 검증

Node.js 22 이상:

```sh
npm ci
npm run check
# 선택: 브라우저가 설치된 환경에서
npx playwright install chromium
npm run test:browser
```

브라우저 테스트는 API 모의 객체를 사용합니다. 공식 RisuAI 통합 테스트를 대신하지 않습니다. `CHROMIUM_PATH`로 기존 브라우저 실행 파일을 지정할 수 있습니다.

25개 로직/DOM 테스트와 파일 전체 정적 검사를 통과했습니다. 실제 공식 웹 설치·모델 응답·장시간 플레이·모든 아이템 조합의 밸런스는 미검증입니다. 현재 작업 환경에서는 Chromium 공유 라이브러리 누락으로 브라우저 테스트가 실행되지 않았습니다.
