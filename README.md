# Risulike RPG · v0.1

RisuAI API v3용 던전 RPG 플러그인입니다. 직업 16종, 스킬 91개, 패시브 117개, 장비 196개, 적 51종과 5개 캐릭터 저장 슬롯을 제공합니다.

사용자가 제공한 기존 `9.1.4` 파일을 바탕으로 GitHub 배포 버전을 **0.1부터 새로 시작**합니다. `package.json`만 npm 형식에 맞춰 `0.1.0`입니다. 내부 플러그인 이름과 기존 저장 키는 유지합니다.

## 설치

1. `Risulike RPG.js`를 다운로드합니다.
2. 기존 버전 사용자는 게임의 내보내기로 저장 코드를 먼저 보관합니다.
3. RisuAI 설정 → 플러그인에서 JS 파일을 가져옵니다. 같은 이름의 기존 플러그인은 업데이트합니다.
4. RPG 액션 버튼으로 게임을 엽니다.

기본 UI는 공식 클라이언트의 전체화면 컨테이너를 사용합니다. 기존 파일의 floating 지원 탐지는 유지하며, 지원하지 않는 호스트에서는 전체화면으로 동작합니다. 휴식 대화 연결은 RisuAI의 요청 수정 권한이 필요합니다.

일반 설치에 npm이나 별도 서버는 필요하지 않습니다. 이미지는 JS 안에 포함되어 있습니다.

## 새 기능 (cloud/ideas-v0.2 브랜치, 표시 버전은 v0.1 유지)

- **가져오기 미리보기·되돌리기**: 이전 코드를 붙여넣으면 덮어쓸 슬롯의 현재/새 요약을 먼저 보여 주고, **교체하기**를 눌러야 저장합니다. 교체 직전 상태는 복원 지점 1개에 보관되어 📂 슬롯 메뉴의 **되돌리기**로 복구할 수 있습니다.
- **봇 캐릭터 소환**: 채팅 캐릭터가 선택되어 있으면 방 선택 화면에서 런당 한 번씩 그 봇을 동료로 부르거나 특별 보스로 불러낼 수 있습니다. 능력치는 기존 동료/층 보스 데이터를 그대로 쓰고, 봇 카드는 읽기만 합니다.
- **모험 일지 → 채팅**: 사망·클리어 화면에서 이번 런 요약을 복사하거나, 다음 채팅 요청 1회에만 문맥으로 붙일 수 있습니다.
- **런 결과 카드**: 결과를 PNG 카드로 만듭니다. 다운로드가 막힌 환경에서는 화면의 이미지를 길게 눌러 저장하세요. 외부로 업로드하지 않습니다.
- **동료 역할**: 리리스·헬레나의 역할을 기본/공격/보호/탐색 중에서 고릅니다. 기본은 기존 동작과 같습니다.
- **효과·음량 설정**: 메인 메뉴에서 화면 효과(기본/약하게/끄기)와 효과음 음량(0~100)을 조절합니다. 기기의 '동작 줄이기' 설정이 켜져 있으면 처음에는 '약하게'로 시작합니다.

자세한 동작과 수치는 [신규 아이디어](docs/IDEAS.md)에 있습니다.

## v0.1 변경

- 비동기 자동저장 시 플레이어·진행·슬롯을 함께 고정하고 저장 순서를 보장합니다.
- 구형 저장 코드 가져오기에서 저장 완료 전 상태를 지우던 문제를 수정했습니다.
- 가져오는 슬롯 범위와 필수 게임 데이터를 전체 검사한 후 쓰기를 시작합니다.
- 묘지·도감 초기 로드 및 도감 반복 조우 횟수 저장을 수정했습니다.
- 전설 슬롯 선택 변수 누락, 직업명 참조, 이미지 중복 키를 정리했습니다.
- 승리 연출 중복 및 이전 게임의 지연된 승리 처리, 비활성 턴의 쿨다운 소비를 방지합니다.
- 휴식 문맥은 선택한 캐릭터의 일반 채팅 요청에만, 마지막 user 메시지 앞에 추가하고 카드의 depth prompt를 수정하지 않습니다. 휴식 중 저장한 게임을 불러오면 다시 연결합니다.
- `onUnload` 미지원 호스트에서도 RPG 버튼이 등록되고, 일부 필드가 빠진 구버전 슬롯도 불러옵니다.

이전 버전이 이미 카드에 남긴 `<!--RPG_START-->` ~ `<!--RPG_END-->` 구간은 자동으로 삭제하지 않습니다. 기존 휴식 문구가 남아 있다면 해당 카드의 depth prompt에서 그 구간만 제거하세요.

## 개발 및 검증

Node.js 22 이상:

```sh
npm ci
npm run check
# 선택: 브라우저가 설치된 환경에서
npx playwright install chromium
npm run test:browser
```

브라우저 테스트는 API 모의 객체를 사용합니다. 공식 RisuAI 통합 테스트를 대신하지 않습니다. `CHROMIUM_PATH`로 기존 브라우저 실행 파일을, `SCREENSHOT_DIR`로 스크린샷 저장 폴더를 지정할 수 있습니다.

34개 로직/DOM 테스트(v0.1의 25개 + 새 기능 9개)와 파일 전체 정적 검사를 통과했습니다. 이번에는 브라우저 테스트도 Chromium 141(헤드리스, API 모의 객체)에서 데스크톱·모바일 스모크와 새 기능 화면까지 통과했습니다. 실제 공식 RisuAI 웹/앱에서의 설치·권한·iframe 다운로드 허용 여부·모델 응답·장시간 플레이·밸런스(동료 역할 수치 포함)는 미검증입니다.

자세한 내용: [검수 보고서](docs/AUDIT.md), [신규 아이디어](docs/IDEAS.md), [검증 메타데이터](docs/verification.json).
